# 🎸 吉他和弦辨識 & 編曲和聲全能實驗室

一套完全運行於瀏覽器的互動式吉他和弦辨識、把位指法探索與和聲進行編曲實驗室。專為吉他手、指彈編曲者與音樂創作者打造，能即時解析指板按音、探索各類把位、視覺化樂理功能，並一鍵試聽經典流行與指彈進行。

## ✨ 核心功能特色

- **互動式 18 品吉他指板**
  - 擬真琴弦粗細與品位雙標記（Fret Markers）。
  - 音程角色色彩視覺化：**根音**（橘黃）、**和弦內音**（翠綠）、**9/11/13 延伸音 Tension**（天藍）。
  - 支援同和弦多種把位切換（開放把位、CAGED 封閉指法、高把位爵士聲部）。

- **即時和弦辨識與轉位分析**
  - 自由點擊指板任意音符，系統自動比對並辨識三和弦、七和弦、掛留（Sus）、增減（Aug/Dim）與 9/11/13 延伸和弦。
  - 智慧判定最低音（Bass），支援斜線和弦（Slash Chords）與轉位標註。
  - 即時呈現弦位八度（Strings & Octaves）與獨立音名集合（Pitch Classes）。

- **純原生 Web Audio 音訊合成引擎（免安裝任何音檔）**
  - 雙樂器音色切換：**原聲吉他（Acoustic Guitar）** 溫暖撥弦殘響、**平台鋼琴（Grand Piano）** 敲擊泛音共鳴。
  - 支援擬真吉他下刷（Strumming）與鋼琴琶音試聽。
  - **全域快捷鍵**：瀏覽時隨時按下鍵盤 <kbd>空白鍵 (Space)</kbd>，立即試聽當前核心定錨和弦。

- **聯動迷你鋼琴鍵盤（Mini Piano Keyboard）**
  - 指板按音與鋼琴鍵盤即時同步映射，快速掌握和弦在鍵盤上的聲部配置。
  - 智慧八度展開：遇到 9/11/13 延伸和弦自動切換至雙八度，清楚呈現高音張力聲部。
  - 琴鍵支援獨立點擊試音，並標記星號根音與延伸音級數。

- **編曲和聲全能引導系統**
  - **核心定錨探索機制**：在鎖定主核心和弦的前提下，點擊任何衍生和弦即時在指板試聽，不打亂核心樂理分析。
  - **同根同源和弦家族庫**：一鍵展開大調系、小調系、屬和弦變化音、減增和弦及掛留和弦等完整家族。
  - **調性與功能角色深度定位**：解析該和弦在不同調性中作為主和弦（Ⅰ）、下屬和弦（Ⅳ）、屬和弦（Ⅴ）的張力與情緒重力。
  - **走向路徑導引（Predecessors & Successors）**：清晰指引該和弦「通常從哪裡來」以及「通常往哪裡去」。
  - **經典進行公式庫（Iconic Progressions）**：內建流行卡農、四和弦神仙走向、日系動漫王道 4536、小室哲哉進行、安達盧西亞下行、Neo-Soul 漫步等進行，支援一鍵指板試聽。
